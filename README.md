# Hike

Premier projet en iOS natif (Swift / SwiftUI) : une application qui présente des randonnées sous forme de cartes, avec animations, icônes d'app personnalisables et un écran de réglages.

## Fonctionnalités

- Liste de randonnées affichées en cartes (`CardView`)
- Animations personnalisées (`MotionAnimationView`)
- Choix de l'icône de l'application parmi plusieurs designs
- Écran de réglages (`SettingsView`)
- Tests unitaires et tests UI inclus

## Stack technique

- Swift / SwiftUI
- XCTest (HikeTests, HikeUITests)

## Lancer le projet

Ouvrir `Hike.xcodeproj` dans Xcode et lancer sur simulateur ou appareil iOS.
